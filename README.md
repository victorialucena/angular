Repositório criado durante meus estudos de **Angular**, com base no curso da [Udemy](https://www.udemy.com/certificate/UC-fe5f9eea-3ab3-4474-b404-7501266753b1/).

O objetivo deste projeto foi praticar os fundamentos do framework e aplicar conceitos como componentes, diretivas, serviços e rotas.

### 📚 Conteúdos abordados:
- Criação e estruturação de projetos Angular
- Componentização e reutilização de código
- Serviços e injeção de dependência
- Data binding e diretivas
- Navegação com Angular Router
- Boas práticas no desenvolvimento com Angular

### 🛠️ Tecnologias utilizadas:
- Angular
- TypeScript
- HTML
- CSS
